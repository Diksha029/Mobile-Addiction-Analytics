# Mobile-Addiction-Analytics
Interactive Power BI dashboard analyzing smartphone usage patterns, screen time behavior, app engagement, and digital wellness indicators to identify mobile addiction trends and user behavior insights.

## Tools Used
-Power BI
-Excel

## Key Insights
-Screen time trends by age
-sleep hours analysis
-Addiction level by occupation 
-Gendder-wise user distribution
